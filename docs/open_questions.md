# 확인이 필요한 사항

요구사항 기반으로 MVP 뼈대를 먼저 구성했으며, 아래는 구현 고도화 전에 확정이 필요한 항목입니다.

1. 날씨 데이터 소스
   - 어떤 API(기상청/OpenWeather 등)를 사용할지
2. RAG 저장소
   - 벡터DB(FAISS/Chroma/Pinecone 등) 및 임베딩 모델 선택
3. 일정 알고리즘
   - 작업 순서 자동 배정 시 우선순위 규칙(구역/자재/인력 숙련도 가중치)
4. 엑셀 출력 포맷
   - 템플릿 고정 여부 및 회사별 커스텀 필요성
5. 인증/권한
   - 다중 현장/다중 관리자 계정이 필요한지 여부
