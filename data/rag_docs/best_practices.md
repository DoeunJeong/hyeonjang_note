# 방수 시공 모범 사례

## 실제 현장 사례

### 사례 1: 세대 욕실 우레탄 시공 (60m²)

#### 상황
- **대상**: 주거용 아파트 욕실
- **계절**: 봄 (4월, 온도 15°C, 습도 60%)
- **문제점**: 기존 방수 도막 박리, 누수 이력
- **예산**: 500만원

#### 시공 계획
```
Day 1: 표면 준비 및 프라이머 도포
- 오전: 기존 도막 제거, 표면 청소 (4시간)
- 오후: 프라이머 도포 1회 (2시간)
- 건조: 야간 (최소 8시간)

Day 2: 중塗 도포
- 오전: 중塗 1차 도포 (3시간)
- 오후: 건조 중 (최소 8시간)

Day 3: 중塗 2차 + 마감
- 오전: 중塗 2차 도포 (3시간)
- 오후: 건조 중 (최소 8시간)

Day 4: 마감재 도포
- 오전: 마감재 도포 (2시간)
- 하후부터: 거주 가능 (72시간 후 풀더 사용)
```

## 우수 사례 핵심 팁

### 준비 단계
1. **날씨 확인**
   - 최소 3일 사전 날씨 확인
   - 비 올 확률 10% 미만인 날 선택
   - 습도 50~85% 범위 내 양일 확보

2. **표면 처리**
   - 기존 방수층이 있으면 완전 제거
   - 먼지/오일 제거 필수
   - 미세한 균열도 먼저 메우기

3. **자재 준비**
   - 실제 면적 + 20% 여유량 준비
   - 온도 맞춤: 냉각/가열 차량 대비
   - 혼합기계 미리 점검

### 시공 단계
1. **균등 도포**
   - 롤러 또는 분사기 사용
   - 두께 편차 최소화 (±0.2mm)
   - 에지/모서리 강화 도포

2. **건조 시간 준수**
   - 온도계로 실시간 확인
   - 습도계로 환기 판단
   - 절대 서두르지 않기

3. **품질 검사**
   - 각 층마다 육안 확인
   - 에지 강도 손가락 터치 테스트
   - 완성 후 물 뿌려 흐름 확인

### 마무리 단계
1. **문서화**
   - 시공 사진 촬영 (각 단계별)
   - 자재 영수증 보관
   - 보증서 발급

2. **고객 설명**
   - 완전 경화 시간 안내
   - 습도 관리 방법 설명
   - 유지보수 주기 안내

## 흔한 실패 사례 & 교훈

### 실패 1: 습도 무시
- **상황**: 우천 직후 강행 시공
- **결과**: 도막 박리, 기포 발생
- **교훈**: 습도 85% 이상 시 절대 금지

### 실패 2: 저가 자재 남용
- **상황**: 저가 프라이머로 비용 절감
- **결과**: 중塗 도포 후 들뜸 현상
- **교훈**: 중장기 품질 보증이 더 저렴

### 실패 3: 건조 시간 단축
- **상황**: 고객 압박으로 24시간 후 마감
- **결과**: 내부 수분 남음, 1년 후 박리
- **교훈**: 표준 건조 시간은 필수

### 실패 4: 표면 처리 상태 불량
- **상황**: 기존 도막 일부만 제거
- **결과**: 경계면에서 박리
- **교훈**: 철저한 표면 준비가 성공의 80%
